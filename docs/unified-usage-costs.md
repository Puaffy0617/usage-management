# 账号统计 v2：费用估算与自动刷新

`4.0.25-usage.3` 补充持续可见的同步状态、原生焦点恢复修复和独立的官方线程累计明细。账号日汇总缺少模型分项时仍不能计算其完整金额。查看[同步与线程明细说明](unified-usage-refresh.md)了解两种来源的覆盖范围。

打开 **使用量 → 账号统计**，可查看人民币 API 等值估算、已报告请求数、Token 和缓存命中率，以及 UTC 每日热力图。下方按账号、模型或每日记录展开；账号筛选只改变显示范围。

## 金额代表什么

**API 等值估算不是 ChatGPT 订阅账单、实际扣款或剩余额度。** 它按当前模型价格表估算这些已报告 Token 如果按 API 标准配置计价，大约对应多少金额：

```text
美元估算 =（新增输入 × 输入单价 + 输出 × 输出单价
          + 缓存读取 × 读取单价 + 缓存写入 × 写入单价）÷ 1,000,000
人民币估算 = 美元估算 × USD/CNY 汇率
```

每个模型分别匹配现有价格表，再合计兼容记录；你修改的模型价格会继续生效。不会用相近模型的价格替代未知模型。这里使用配置的标准单价，不能从一天的 Token 总量推断单次请求的长上下文档位、缓存保留时长或其他计费优惠。价格依据可查 [OpenAI API 定价](https://developers.openai.com/api/docs/pricing) 和 [GPT-6.1 Sol 模型说明](https://developers.openai.com/api/docs/models/gpt-6.1-sol)。

## 为什么有些数字是「—」或带「\*」

费用需要明确的模型、输入/输出以及缓存读取/写入计数。导入数据可用 `input_tokens_total` 表示含缓存输入，或用 `input_tokens_fresh` 表示新增输入，并明确提供其余计数。含缓存输入会先减去缓存部分再计新增输入费用，避免重复收费。缺少缓存计数不会自动当作零；含义不明确的 `input_tokens`、仅有 Token 总数或未识别的 Token 指标不能直接计价。

- **「—」**：来源未报告该指标，或缺少模型、价格、完整计数或可用汇率。它不表示免费或零用量。官方账号接口可能只返回没有模型分项的 Token 总数，此时仍能显示已报告 Token，费用保持不可用。
- **「\*」/部分覆盖**：只计算已知部分。例如同时存在无模型总数和具名模型明细时，保留具名模型的已知小计，忽略可能重复的总数。存在无法确定的平台/功能重叠时，相关记录会排除。
- 请求数仅来自明确报告的请求计数，不由聊天消息数推算。缓存命中率为缓存读取 Token ÷ 含缓存输入 Token；缺少所需计数时保持不可用。

数据按来源、覆盖范围、报告性质及时间粒度分组。每日记录与累计快照、官方账号数据与本地记录、不同覆盖范围不能相加。额度百分比和积分余额单独展示，不换算成钱。选择「全部账号」只合计同一组中兼容的记录，不能据此声称覆盖全部 ChatGPT 网页、手机和桌面活动。

## 人民币汇率

账号视图默认自动获取真实公开 USD/CNY 报价，使用 24 小时查询缓存，可见时到期刷新；账号每两分钟同步不会反复请求汇率。主来源为 [ExchangeRate-API](https://www.exchangerate-api.com/)，失败时由现有服务尝试 [FloatRates](https://www.floatrates.com/)。页面保留来源链接和**获取时间**；该时间是应用取数时间，不代表实时成交报价。免费来源本身按日更新，见 [ExchangeRate-API 免费接口说明](https://www.exchangerate-api.com/docs/free)。

刷新失败但仍有有效旧缓存时，页面明确标记使用上次汇率；从未取得有效 CNY 汇率时显示「—」，不会填入静态默认值。此账号视图不改写原设备用量视图的手动汇率设置。

## 两个账号如何自动刷新

默认开启**每 2 分钟刷新所有已连接账号**，在账号统计页面打开、可见且窗口处于前台时运行。管理账号中可关闭，或改为每 1/2/5 分钟。切到后台、离开页面或关闭应用后暂停；回到页面时检查到期账号。显示筛选为账号 A 时，账号 B 仍会刷新，无需切换当前提供商或正在使用的账号。顶栏同步操作也刷新全部已连接账号。

每个账号独立处理。临时错误保留历史并按间隔重试；授权失效需要重新授权，不会凭空补齐失败期间的用量。开发验证使用隔离测试数据，未读取你的真实账号凭据，也未完成真实双账号同步验收；现有数据源限制见 [来源说明](unified-usage-sources.md)，检查记录见 [验证报告](unified-usage-testing.md)。
