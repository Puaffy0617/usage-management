# 后台同步与无控制台启动

`4.0.25-usage.4` 将账号采集交给一个原生后台任务。默认开启，间隔两分钟；应用仍在运行时，最小化、托盘、切换页面或切换到其他软件都不会暂停采集。完全退出 CC Switch 后任务随进程停止，没有另装 Windows 服务或系统计划任务。

## 设置与同步状态

在 **使用量 → 账号分析 → 管理账号** 中调整全局后台开关和一、二、五分钟间隔。每个账号保留已有正数间隔覆盖，零表示跟随全局。关闭全局后台开关会停止后续自动采集；手动同步仍可使用。正在进行的请求会保留正常完成的结果。

原生任务按持久化的检查记录判断到期时间，错误也遵守间隔。未完成授权、已解绑或明确要求重新授权的账号不反复尝试。手动同步与后台任务共用同一个批次锁及账号锁；已有同步运行时，手动按钮复用进行中的任务状态，不排队重复查询。前端每三十秒读取已保存结果，并响应原生更新通知；前端页面不再负责发起周期性采集。

页面顶部提供原生任务运行状态、上次尝试、完成时间和下次检查时间。金额摘要单独展示官方实际返回的已发现线程累计美元估算、人民币换算及精确线程 Token；主卡片的账号日汇总保持独立。线程未返回、无法确定跨账号归属或缺少美元字段时，会保留相应的不可用/部分覆盖说明。

## CMD 弹窗的处理

官方 npm Codex 启动链是批处理 → Node → 原生程序。仅隐藏父批处理或 Node，无法阻止 Node 创建可见的原生子进程。新版对非交互式 Codex 命令直接使用同一安装中的匹配原生 Windows 程序，并设置无控制台创建标志。版本探测、账号同步和内置模型目录探测共用此路径。

支持经元数据核对的标准 npm 安装、旧版随包原生目录，以及选定的原生 `codex.exe`。解析器检查平台架构、包版本与安装目录关系。自定义脚本包装器无法核对时，会返回清楚的错误而不启动脚本。手动“打开终端”等交互功能维持原有行为。

无控制台验证使用隔离的 Windows 子进程，检查其 `GetConsoleWindow` 为空。开发还对当前安装运行了同一个解析器的只读元数据检查；没有执行真实 Codex 认证或用量请求。

## 模型价格与汇率

沿用原有 models.dev 价格自动同步设置。应用启动后每十五分钟检查是否到期，距上次成功满六小时才重新取数，不依赖当前页面或窗口焦点。除最近的常用模型外，也会更新所有已配置、且能在相应原厂目录中精确匹配的模型；明确选中的供应商仍优先。关闭原有模型价格自动同步开关会停止这一路径。

自动导入不会把目录未提供的缓存单价写成零：已有的有效配置会保留，新模型缺少必要价格时跳过。明确报告的零价仍是零价。网络错误保留原价格，小于可支持精度的正价格不会被舍入成免费。手动与自动价格请求共用进行中的任务。

人民币汇率使用已有的真实公开 USD/CNY 来源和每日缓存；失效时显示旧汇率或不可用状态。官方线程美元估算与按本地模型单价计算的 API 等值估算保持各自标签；都不是 ChatGPT 订阅实际扣款。官方日汇总缺少模型/输入输出分项时，不能仅凭总 Token 计算整份日汇总的金额。详细覆盖范围见[线程明细说明](unified-usage-refresh.md)。
